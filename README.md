# «Хвиля» — интернет-магазин аудиотехники

Многостраничный демо-магазин навушників, колонок, вінілу та підсилювачів. Портфолио-проект: всё работает без сервера — каталог в локальных файлах, «бэкенд» — моки, корзина, избранное, сравнение и заказы — в `localStorage`. Сайт двуязычный: украинский и английский.

SvelteKit 3 · Svelte 5 (runes) · строгий TypeScript · Tailwind CSS 4 · `@sveltejs/enhanced-img` · `@lucide/svelte`. Все публичные страницы пререндерятся (SSR на сборке), хостинг — любой статический (GitHub Pages). Результаты проверки — в [AUDIT.md](AUDIT.md).

## Запуск

Нужен Node.js 22+.

```sh
npm install
npm run dev          # http://localhost:5173
```

## Проверки

```sh
npm run check        # svelte-check (типы, a11y-предупреждения)
npm run lint         # prettier + eslint
```

## Сборка

```sh
npm run build        # статический сайт в build/ (72 HTML-страницы + JSON-«API»)
npm run preview      # http://localhost:4173
```

Под подпапку (GitHub Pages): `BASE_PATH=/hvylia npm run build`.

Workflow `.github/workflows/deploy-pages.yml` собирает и публикует сайт при пуше в `main`. Один раз: **Settings → Pages → Source: GitHub Actions**.

## Как устроен «бэкенд»

| Что                                                                                          | Где                             |
| -------------------------------------------------------------------------------------------- | ------------------------------- |
| Данные: товары, бренды, категории, отзывы, SEO-страницы, Нова Пошта                          | `src/lib/data/`                 |
| Сервисы для пререндера (сводки товаров, страницы каталога)                                   | `src/lib/server/`               |
| Фильтры, фасеты со счётчиками, сортировка, пагинация (общий для сервера и браузера)          | `src/lib/catalog/query.ts`      |
| Статические JSON-эндпоинты: `/api/catalog.json`, `/api/np.json`, `/api/products/[slug].json` | `src/routes/api/`               |
| Мок-API в браузере: товары, поиск, отделения НП, создание заказа (задержка 200–600 мс)       | `src/lib/api/client.ts`         |
| Корзина, избранное, сравнение, недавно просмотренные                                         | `src/lib/stores/shop.svelte.ts` |

Фильтры и сортировка синхронизированы с URL (`?brand=aurel&anc=1&sort=cheap&page=2`). Сервер рендерит раздел без фильтров (полный HTML для поисковиков), браузер применяет параметры из адреса.

## Языки

Каждая страница пререндерится дважды — `/uk/…` и `/en/…`. Корень `/` — маленькая страница-развилка: если язык уже выбран вручную (`localStorage.lang`), открывает его, иначе смотрит на часовой пояс браузера — Украина получает украинский, остальные страны английский. Переключатель UA/EN в шапке остаётся на той же странице и запоминает выбор.

- `src/lib/lang-core.ts` — текущий язык и подписка `onLang` (без `$app`, его импортирует `params.ts`); `src/lib/lang.ts` — `lhref()` и `switchHref()` для ссылок с префиксом языка.
- Строки интерфейса — `src/lib/ui.ts` (`tUk`/`tEn`), данные — `src/lib/data/*.uk.ts` и `src/lib/data/en/*`. Английские файлы содержат только тексты; цены, фото и наличие общие. Имена, города и адреса «Новой почты» — официальная транслитерация КМУ-2010 (`translit.ts`).
- Модули `src/lib/data/{name}.ts` переключают экспорт через `onLang`; язык выставляется в `hooks.server.ts` при пререндере и в `[lang]/+layout.svelte` в браузере.
- SEO: `<html lang>`, `hreflang`, `og:locale`, двуязычный `sitemap.xml`.

## Демо-данные

- Промокод **HVYLIA10** — −10%.
- Тестовая карта **4242 4242 4242 4242**, любой будущий срок и CVV. Данные карты не сохраняются даже в браузере.
- Заказ открывается по адресу `/order?id=HV-…` и хранится только в этом браузере.

Домен для canonical, OG и sitemap — `https://hvylia.com.ua` (заглушка, `src/lib/data/site.ts`). Фото — Unsplash, авторы в `src/lib/assets/products/CREDITS.json`; бренды вымышленные. Вырезанные без фона версии (`src/lib/assets/cutouts/{slug}.png`) сделаны из тех же фото; если для товара вырезки нет, сайт показывает обычное фото. Графики АЧХ — демонстрационные данные (`src/lib/audio/fr.ts`).
